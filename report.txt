W1 One Set press, hop by hop, from browser back to browser:
Clicking Set sends an HTTP POST to setpoint, which flask publishes to MQTT for the node to apply and publish a new reading back to the broker. The Flask MQTT listener updates latest and the browsers get/api/light poll fetches and displays the updated value.
W2 Why does the dict "latest" exist? One sentence:
The latest dict stores the most recent telemtry snapshot in memory so HTPP get/api/light requests can respond immediatly without waiting on sensor hardware or MQTT traffic. It also shares state safely between the background MQTT client thread and Flask request handlers.
W3 How old can the number on the page be, in seconds, and why:
the number can be Tnode + Tpoll seconds old equal to one full node oublish period plus one full browser poll period. This worst-case delay happens if a reading is published right after a browser poll finishes, forcing it to wait a full publish cycle and a full poll cycle before appearing on screen.
